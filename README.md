# Larkhearth assets

Public images for the Larkhearth B2B storefront demo, served with GitHub Pages:
`https://juanmoguel.github.io/larkhearth-assets/images/<file>`

Product images are named by SKU (e.g. `LH-XM-0142.webp`). Source of truth is
`design/images/` in the larkhearth-storefront repo; the seed script
(`scripts/demo-data/seed.mjs --assets-base-url ...`) links them in Salesforce CMS.
